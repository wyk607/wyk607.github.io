1. 有理数的概念与分类

核心概念：有理数是整数（正整数、0、负整数）和分数的统称，所有有理数都可以表示为两个整数之比（分母不为0），记作Q。数轴是表示有理数的重要工具，数轴三要素：原点、正方向、单位长度，任何一个有理数都可以用数轴上的一个点表示。

1. 有理数集合：Q = { 整数 ∪ 分数 }
2. 数轴表示：若a是正数，则a在原点右侧；若a是负数，则a在原点左侧
例题：
在数轴上表示下列有理数：3、-2、0、1/2、-1.5
解：原点右侧3个单位表示3，左侧2个单位表示-2，原点表示0，右侧0.5个单位表示1/2，左侧1.5个单位表示-1.5

2. 有理数的加减乘除运算

核心法则：加法遵循"同号得同、异号得异"，减法可转化为加法（a - b = a + (-b)）；乘除法遵循"同号得正、异号得负"，先确定符号，再计算绝对值。运算顺序：先算乘方，再算乘除，最后算加减；有括号先算括号内（小括号→中括号→大括号）。

1. 加法交换律：a + b = b + a
2. 加法结合律：(a + b) + c = a + (b + c)
3. 乘法交换律：a×b = b×a
4. 乘法结合律：(a×b)×c = a×(b×c)
5. 分配律：a×(b + c) = a×b + a×c
例题：
计算：(-3)×(-2) + 5 - (-4)÷2
解：先算乘除：(-3)×(-2)=6，(-4)÷2=-2，原式=6 + 5 - (-2)=6+5+2=13
